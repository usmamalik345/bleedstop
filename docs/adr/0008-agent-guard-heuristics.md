# ADR-0008: Deterministic agent guard; held-out numbers are the ones we quote
**Decision.** Regex families (override, reset, restriction removal, system prompt probe, fake delimiters, tool hijack, exfil URL, markdown beacon, secret request, encoded payload, indirect markers), secret patterns in network tool arguments, tool-call loop and velocity per session, and agent recursion depth. An optional lexical scorer exists but measured **no lift**. Rules were tuned on a dev set (96.4% detection); a held-out set written afterwards and never tuned on scores **22.5%** detection at 0% blocking FP.
**Consequences.** It reliably stops the cost side (loops, velocity, recursion, secret exfil via tools: 7/7 sequences, 0/5 benign) but is not a general prompt injection defence. Next step: a small learned classifier evaluated on the same held-out split.
